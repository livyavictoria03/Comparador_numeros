# Comparador de Números

Programa em Python que recebe dois números e informa qual deles é maior ou se são iguais.

## Funcionalidades
- Entrada de dois números
- Comparação entre valores
- Exibição do maior número
- Verificação de números iguais

## Tecnologias
- Python 3

## Como executar
1. Execute o arquivo `.py`
2. Digite os números solicitados
3. Veja o resultado da comparação
